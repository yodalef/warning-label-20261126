A Python program that writes the safety warning label that should come printed on every human being — leaks from the eyes at sad movies, malfunctions before coffee, needs snacks every 3 hours, no mute button — to /output/entry.txt. The line is UTF-8 text of 154 characters, within the bounty's 160-character limit. Deterministic and offline: no network use.

## Run it

```sh
python3 main.py
```

Writes the line to /output/entry.txt (or ./output/entry.txt when /output is not writable).
